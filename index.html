IT Tech Support Tool Kit

A portable Windows troubleshooting toolkit for IT technicians: a diagnose-and-fix dashboard with a guided Troubleshooting Wizard, and a separate read-only PC assessment that produces one HTML report. It runs inside Windows on a PC that already starts; it is not a bootable or recovery tool.

Run it

Open PowerShell and paste one of these commands. They set TLS 1.2 and handle a download that arrives as bytes, which the shorter irm … | iex form does not always do.

Support dashboard (online, no copy kept)

Downloads a verified release, runs it from a temporary protected folder and deletes the folder when you close the toolkit. Asks for administrator rights. No portable apps are downloaded.

[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; $r=(iwr -UseBasicParsing https://jlesc2026.github.io/toolkit).Content; if($r -is [byte[]]){$r=[Text.Encoding]::UTF8.GetString($r)}; iex $r.TrimStart([char]0xFEFF)

PC assessment (read-only report)

Checks hardware, storage health, security, drivers and recent crashes, then saves one HTML report to the Desktop. The report is kept and contains the computer name, user name, serial number and MAC addresses, so share it only with people who support that PC.

[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; $r=(iwr -UseBasicParsing https://jlesc2026.github.io/assess).Content; if($r -is [byte[]]){$r=[Text.Encoding]::UTF8.GetString($r)}; iex $r.TrimStart([char]0xFEFF)

Flash-drive copy (with your portable apps)

Builds or updates IT-Toolkit\ on a USB drive, then you start it with START.bat. Updating keeps your PortableApps, Logs, Reports and settings. No administrator rights needed to build it.

[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; $r=(iwr -UseBasicParsing https://jlesc2026.github.io/install).Content; if($r -is [byte[]]){$r=[Text.Encoding]::UTF8.GetString($r)}; iex $r.TrimStart([char]0xFEFF)

What the online mode does and does not do

Minimal footprint, not zero trace. It runs from a temporary protected folder and deletes it on exit, then checks that the folder is gone. Windows and security-software logs are not affected.

It doesIt does not
  • Download a published release and check its SHA-256 hash before running anything
  • Use a new, randomly named folder under C:\ProgramData that only administrators and SYSTEM can open, and refuse links
  • Switch the toolkit's disk logging off for the session
  • Verify the deletion and warn you if anything remains
  • Remove the command you typed from your shell history
  • Touch Windows event logs, PowerShell or process-creation logging, antivirus or EDR history, Prefetch or the DNS cache
  • Keep reports made during the session: they are deleted with the folder, so copy them out first
  • Delete the assessment's HTML report, which is saved to the Desktop

Verified releases

The launchers never run whatever is on the main branch. Each reads manifest.json from this site, downloads the matching release file from GitHub Releases and compares its SHA-256 hash. If the hash does not match, or the manifest points anywhere other than this project's releases, nothing runs. A new version only reaches these links when a release is published.

Before you use it

  • Use it only on computers you are authorized to support. The tools can change services, networking, system files and devices. There is no warranty; try it on a spare PC or virtual machine first.
  • Security software may react. The launchers start PowerShell with -ExecutionPolicy Bypass and the online mode runs a downloaded script as administrator.
  • Requires Windows 10 or 11 with the built-in Windows PowerShell 5.1. Most tools work offline once the toolkit is on the PC. Some output expects an English version of Windows.
